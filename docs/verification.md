## 相比原包的修复

- CSV 缺列单元格、重复表头和无效供应者现在明确拒绝，避免异常中断或未解析链接。
- 清单流语义/地域变化后拒绝旧批准映射；数量倍率可以使用相同供应者。
- 原生解析按段处理，避免把 Comment 的 Products 字样误认成标题，拒绝未知段与不完整对象。
- 生成过程不继承模板的旧技术、验证和来源说明；拒绝重复参考产品名。
- 输出及既存 manifest 不覆盖；情景参数先验证，整批失败不留下已发布的半批文件。
- 原生编码由用户显式提供，防止中文导出被自动按西文解码而产生乱码。
- LCIA 标签不能为空，阶段必须明确，拒绝混用表征/归一化等结果、非有限值、重复指标及单位冲突；提示缺失类别。
- GUI 校验进程身份及精确窗口名；输入默认关闭，固定确认字段不等于用户授权。
- self_check.ps1 会传播测试失败退出码，并检查 MCP 协议连接。

## 明确未完成的实机验证

没有本机真实简单过程 CSV 模板、真实导入日志和原生结果表，因此未验证候选被 SimaPro 9.0 接受、导入链接是否正确、自动操作是否成功触发 Calculate，以及实际 LCIA 的数值。

普通桌面授权等级、项目启用的背景库/版本/系统模型、实际方法版本尚未确认。复制结果工具只证明读取剪贴板，不证明来源。

原生候选只支持单输出 material + 正数 technosphere inputs。排放、废物、回收信用、多输出、分配及参数不自动序列化。工程指南指导完整录入，不能删掉这些流来绕过限制。

未测试 Windows 锁屏、远程会话、不同语言/DPI、自绘控件、长批次或 GUI 输入；不提供无人监督全自动 SimaPro 运算的承诺。当前文件不支持直接 XLSX 和逗号小数结果读取。
